# dssarl.com

Company website of Digital Services SARL (WordPress plugins), served by GitHub Pages at https://dssarl.com/.

Static pages (EN/FR/AR):

- `index.html`: company home page with the plugin cards.
- `orderproof/index.html`: OrderProof product page, https://dssarl.com/orderproof/.
- `cityfee/index.html`: CityFee product page, https://dssarl.com/cityfee/.
- `upgrade-checker/index.html`: Upgrade Checker product page, https://dssarl.com/upgrade-checker/ (screenshots `screenshot-1.jpg`, `screenshot-3.jpg`, `screenshot-4.jpg` in the same folder).
- `cityfee/guide-city-delivery-fee/index.html`: CityFee setup guide (EN/FR/AR), https://dssarl.com/cityfee/guide-city-delivery-fee/.
- `guides/php-8-2-end-of-life/index.html`: PHP 8.2 end-of-life guide (EN/FR only), https://dssarl.com/guides/php-8-2-end-of-life/.

`CNAME` holds the custom domain.
