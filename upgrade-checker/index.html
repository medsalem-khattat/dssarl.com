Upgrade Checker

PHP Compatibility Scanner

Your host wants you on a newer PHP version. Upgrade Checker scans the plugins and themes on your own server and flags likely incompatibilities with the PHP version you choose, so you know where to look before you switch.

What Upgrade Checker does

Runs on your own serverThe scan reads the PHP files on your server. No outside service, no account, and your code is never sent anywhere.
Premium and custom code includedBecause the scan is local, it also covers premium and custom plugins and themes that are not on WordPress.org.
Target PHP up to 8.5Pick one released PHP version (7.0 to 8.5) and check against it, without alerts about versions that do not exist yet.
Built for shared hostingShort, resumable batches with a progress bar. Close the tab and the scan continues in the background. Cancel at any time.
Results by plugin, rule and fileErrors first, then warnings, grouped by plugin or theme, then by rule and by file and line. An "update available" hint shows where updating first may help.
Focus on code that runsIgnore a rule or a file you have already reviewed. Third-party and development code (such as vendor and tests folders) is labelled and can be hidden.
Read-onlyUpgrade Checker never changes your files and never changes your PHP version. It shows you where to look; it does not fix code.

How it works

  1. Go to Tools > Upgrade Checker (administrators only).
  2. Choose the PHP version you plan to move to.
  3. Choose the plugins and themes to scan. Your active plugins and theme are selected by default.
  4. Click Scan and follow the progress bar.
  5. Read the results, then update, contact the plugin author or ask a developer, and test on a staging site before you change PHP.

Please read

These results come from automated static analysis and are guidance only. They may include false alarms and may miss problems. A clean result does not guarantee your site will work on this PHP version. Back up and test on a staging site before changing PHP.

Privacy: scanning runs entirely on your own server. Upgrade Checker does not send your code, files, scan results or any other site data anywhere.
